Google Apps Script Setup Guide
1

Open your Google Sheet

Open the Kalinga Attendance Google Sheet. Go to Extensions → Apps Script

2

Paste this code in the editor

Delete existing code and paste the following:

function doGet(e) { const ss = SpreadsheetApp.getActiveSpreadsheet(); const sheet = ss.getSheetByName("RAW ATTENDANCE"); const data = sheet.getDataRange().getValues(); const headers = data[0]; const rows = data.slice(1).map(row => { let obj = {}; headers.forEach((h, i) => obj[h] = row[i]); return obj; }); return ContentService .createTextOutput(JSON.stringify({status:"ok", data: rows})) .setMimeType(ContentService.MimeType.JSON); }
📋 Copy Code
3

Deploy as Web App

Click Deploy → New Deployment → Select type: Web App
Execute as: Me | Who has access: Anyone
Click Deploy → Copy the Web App URL

4

Paste URL in Settings

Go to Settings → Google Apps Script URL → Paste the copied URL → Save
